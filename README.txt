CATÁLOGO SEBAS SELEC — INSTRUCCIONES FÁCILES
============================================
Esta web es una PRIMERA VERSIÓN DE MUESTRA. Los 8 productos, los precios y las ilustraciones son ejemplos.
No está publicada en internet y el WhatsApp aún no está conectado.

ARCHIVOS
- index.html: abre la tienda.
- productos.js: datos de tu negocio y artículos.
- editor.html: panel para actualizar los datos sin programar (lo incluiremos en el archivo ZIP).
- imagenes/: imágenes de demostración (cámbialas por tus fotos reales).

1) VER LA TIENDA
   Extrae el ZIP y abre index.html en Chrome, Safari o Edge. Mantén juntos todos los archivos.

2) PERSONALIZAR SIN PROGRAMAR
   Abre editor.html, cambia la marca y agrega tu WhatsApp en formato internacional, sin el +.
   Por ejemplo, para Estados Unidos el prefijo es 1; para Bolivia es 591.
   No uses el número de ejemplo para tu negocio.
   Edita los productos y haz clic en "Descargar productos.js".
   Reemplaza el archivo original productos.js por el nuevo. Luego vuelve a abrir index.html.

3) PONER FOTOS REALES
   Crea imágenes JPG o PNG con nombres simples (perfume1.jpg, reloj1.jpg, etc.).
   Guárdalas en la carpeta imagenes/ junto a las imágenes de ejemplo.
   En editor.html, en "Imagen", escribe imagenes/perfume1.jpg.
   También puedes usar un enlace DIRECTO https://... a una imagen que controles y permita acceso público.

4) PUBLICAR GRATIS CON GITHUB PAGES
   a. Abre https://github.com/ y crea tu cuenta.
   b. Crea un repositorio PUBLIC llamado TUUSUARIO.github.io (reemplaza TUUSUARIO con tu cuenta).
   c. Sube index.html, productos.js y la carpeta imagenes/ a la raíz. Conserva editor.html en tu dispositivo.
      Puedes usar "Add file" > "Upload files" en GitHub para todos los archivos a la vez.
   d. Ve a Settings > Pages > Build and deployment.
   e. Elige "Deploy from a branch", branch "main", folder "/ (root)" y pulsa Save.
   f. GitHub mostrará la dirección https://TUUSUARIO.github.io/ cuando esté publicada.
   g. Para actualizar luego, sustituye productos.js y las imágenes en el repositorio.

IMPORTANTE:
- No se reciben pagos dentro de esta web: dirige consultas a WhatsApp.
- El editor trabaja en tu navegador y NO actualiza GitHub automáticamente.
- El archivo editor.html también sería público en GitHub Pages. Es un editor local (no guarda en servidor), pero si prefieres no mostrarlo, no subas editor.html al publicar. Solo súbelo a tu propia computadora.
- No afirmes que los productos de prueba existen; reemplázalos antes de ofrecerlos.
- Para vender productos de marcas, utiliza descripciones y fotografías honestas sobre su procedencia y autenticidad.
